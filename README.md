# 📊 FinTrack — AI Financial Dashboard

An intelligent financial tracking dashboard featuring real-time portfolio analytics, spending insights, and interactive data visualizations with a stunning glassmorphism UI.

## ✨ Features

- **Portfolio Overview** — Track total balance, investments, and net worth at a glance
- **Interactive Charts** — Dynamic pie charts, line graphs, and bar charts powered by Chart.js
- **Spending Analytics** — Categorized expense tracking with visual breakdowns
- **AI Insights** — Smart financial recommendations based on spending patterns
- **Real-Time Data** — Live-updating dashboard with animated data transitions
- **Dark Glassmorphism UI** — Premium frosted-glass design with gradient accents
- **Responsive Layout** — Optimized for desktop and mobile viewing

## 🛠️ Tech Stack

| Technology | Usage |
|-----------|-------|
| **JavaScript (ES6+)** | Dashboard logic, data processing |
| **Chart.js** | Interactive charts and visualizations |
| **CSS3** | Glassmorphism, animations, gradients |
| **HTML5** | Semantic dashboard layout |
